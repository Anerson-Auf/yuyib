# interaction-smoke

Минимальный проект для проверки Interactable (**E**) и Trigger volumes.

См. [`../AUTHORING_GUIDE.md`](../AUTHORING_GUIDE.md).

1. Editor → Open Project → эта папка (`project.yuyib`).
2. Play.
3. К `TalkNpc` → **E** → signal `world.talk_npc`.
4. В `ExitVolume` → signals `trigger.level.exit` (`entered` / `stayed` / `exited`).
